# Batch number tracking

Running log of batch/lot numbers issued per compound, kept here so they stay
in order and nothing gets reused or skipped by accident. Updated
conversationally — tell Claude the compound and the new batch number any
time one comes in, and it gets appended below.

This is separate from the app's own `Lot` records (Admin → COA Management),
which are what actually drive the public QR-code verification pages and COA
downloads — when a batch here is ready to sell, the same lot number should
be entered there too so the two stay in sync.
